Jobs submitted with an active code go ahead of everyone else's. A job submitted while its code is active keeps its priority after the window closes. Times are in your local time zone.

Queue

Jobs are listed by queue, then in predicted start order (# column); click a column heading to sort by it instead. "Est. time" and "Waited" are for that queue's part of the job: a job that needs Whisper is in the transcription queue first, then moves to the alignment queue. "Submitter" is a short hash of the submitter's browser ID, so the same value means the same person. Cancelling a job stops it (a running one within a few seconds), deletes the upload, and tells the user it was cancelled by the administrator.
