▸ Advanced options

When unchecked, vowels that occur while another speaker is talking are excluded from measurement.

If a vowel is followed by an "L" or "R" within the same word, the two intervals are combined. This, in the case of the word pull, "P + UH1 + L" becomes "P + UHL1".

English only — requires CMU ARPABET stress-marked phone labels.

When checked (default), a liquid is combined with the previous vowel even if it's followed by another vowel in the same word — e.g. the "L" in yellow, or in fuller/pooling where a vowel-initial suffix follows what's really a coda liquid. When unchecked, only word-final or preconsonantal liquids are combined (as in pull or world) — but this also excludes cases like fuller/pooling that arguably should still count, since there's no way to tell those apart from true onset liquids like the one in yellow using phone adjacency alone.
